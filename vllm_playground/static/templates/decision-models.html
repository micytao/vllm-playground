Press Start — every tick, the current track layout becomes one batched Choice+Noul request to the Decision Server.

How it works

Each tick compresses the 3-lane road ahead into a JSON state object and sends a single request with two questions: a Choice (which lane?) and a Noul (collision likely?). The model picks a lane; your code acts on the answer. This is the control-loop pattern — fast, typed decisions driving real-time behavior.
