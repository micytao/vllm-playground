# vLLM Playground v0.2.0 - Decision Models (Experimental)

**Release Date:** October 2026

This release introduces **Decision Models**, a new experimental tab for exploring structured-read decision capabilities powered by DiffusionGemma and the Jev / System One API. It also includes security hardening for debug endpoints and SQL injection prevention.

---

## Highlights

### Decision Models Tab

A brand-new **Decision Models** section under the Experimental category in the sidebar. This is a fully isolated sandbox for structured-read decisions -- it manages its own dedicated container, ports, and lifecycle, so it never interferes with the main vLLM Server flow.

- **Gallery of 12 use cases** across 4 primitive categories, each with a ready-to-run payload:
  - **Noul** (Yes/No Probability) -- Billing Dispute Gate, RAG Passage Reranking
  - **Choice** (Pick One Option) -- Support Ticket Routing, Agent Tool Selection, Citation Verification, Confidence-Gated Model Routing
  - **Score** (Ordered Scale) -- Urgency Scoring
  - **Combination** (Multiple Primitives) -- Chained Multi-Question Triage, LLM Guardrails, Content Moderation, Race Lane Decider, Rubric Grading Puzzle
- **Category tab bar** -- Filter use cases by primitive type with pill-style tabs showing per-category counts, or view all grouped under section headings.
- **Mock-by-default evaluation** -- Every use case can be tried instantly with a deterministic mock evaluator (no GPU required). When a live Decision Server is connected, evaluation is transparently proxied to it.
- **Managed container lifecycle** -- Pull, start, health-wait, and stop a dedicated vLLM nightly container running `google/diffusiongemma-26B-A4B-it`, fully isolated from the main vLLM Server instances.

### Remote Jev Endpoint Support

Connect to an externally-managed Jev API (e.g. `https://api.typesafe.ai`) instead of running a local container.

- **Run Mode toggle** -- Switch between Local (launch a container) and Remote (connect to an existing endpoint) with a single click.
- **Credential validation at connect time** -- The connection flow now sends a probe request to `/v1/systemone` to verify the API key and model before showing "Connected". Previously, only a `/health` reachability check was performed.
- **`jev-latest` default** -- Remote mode defaults to the `jev-latest` model alias (the official Jev API model), not the local DiffusionGemma HuggingFace ID.
- **Settings persistence** -- Remote endpoint URL and API key are saved to and restored from the Settings store.

### New Use Cases from Official TypeSafe Cookbooks

Five new use cases sourced from the most popular Jev production patterns (838 catalogued builds, 545 shipped products):

- **LLM Guardrails** (3x Noul + Score) -- Screen messages for jailbreak, harmful requests, and medical advice with a severity rating. Based on the [Guardrails for LLMs cookbook](https://docs.typesafe.ai/cookbooks/llm_guardrails).
- **Content Moderation** (Choice + 2x Noul) -- Classify chat messages by purpose, flag toxicity, and detect spoilers. Based on the [Twitch Chat Filter cookbook](https://docs.typesafe.ai/cookbooks/twitch_chat_filter).
- **RAG Passage Reranking** (Noul) -- Score candidate passages against a query for search result reranking. Reported 20x faster and 10x cheaper than LLM-based reranking. Based on the [Re-ranking cookbook](https://docs.typesafe.ai/cookbooks/rerank_typesafe).
- **Citation Verification** (Choice) -- Check whether a source document supports, contradicts, or says nothing about a claim. Based on the [Double-checking Citations cookbook](https://docs.typesafe.ai/cookbooks/citation_check).
- **Confidence-Gated Model Routing** (Choice) -- Pick fast/standard/reasoning model tier based on request complexity. The #1 Jev production pattern with 64+ shipped products.

### Interactive Demos

- **Race Lane Decider** -- A live control-loop demo with polished emoji visuals, lane dividers, proximity glow, and crash animation. Each tick compresses lane obstacles into state and asks for the safest lane plus a hazard probability.
- **Rubric Grading Puzzle** -- Grade an entire rubric in a single batched request. The submission and rubric are sent once as shared state, and each criterion becomes one Score question.

## Security

- **Debug endpoint auth gate** (CWE-862) -- Both debug endpoints (`/api/debug/connection` and `/api/debug/test-vllm`) are now gated behind an explicit opt-in environment variable. Previously they were unconditionally exposed.
- **SQL injection template literal fix** -- Resolved a potential SQL injection vector in `utils.custom` string templating.

---

## Upgrade Notes

- This release is backward-compatible. No settings migration is required.
- The Decision Models tab is labeled **Experimental** and is fully isolated from existing vLLM Server and vLLM-Omni flows.
- To use Decision Models locally, you need an NVIDIA GPU and a vLLM nightly container image. Alternatively, connect to a remote Jev endpoint with just an API key.
- See the **[Decision Models Guide](docs/DECISION_MODELS_GUIDE.md)** for full setup instructions.
